## Refreshing public statistics

Run `python scripts/update-activity.py`, `python scripts/update-leetcode.py`, and `python scripts/update-monkeytype.py`, followed by `node scripts/build-profile.cjs --stats-only`. GitHub's collector saves validated data to `data/github.json`; the Node renderer builds Consistency and Git Activity artwork. Existing images are retained if a fetch fails. `.github/workflows/activity.yml` runs these steps daily at 03:17 UTC (11:17 AM Asia/Manila), on manual dispatch, and on generator/workflow changes. Repository rules must permit bot commits.
