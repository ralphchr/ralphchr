# Asset sources and maintenance

- Typography: Inter Black and Inter Regular, plus JetBrains Mono, from the portfolio’s existing `@fontsource` packages. Banner and project lettering is converted to SVG paths, so GitHub does not need custom fonts or external font files. Original font licenses are in `licenses/`.
- Technology and application icons: [Simple Icons 16.0.0](https://github.com/simple-icons/simple-icons/tree/16.0.0), with Adobe and Canva marks from [Simple Icons 13.21.0](https://github.com/simple-icons/simple-icons/tree/13.21.0), recolored cyan and framed locally. Icons are CC0; licenses and trademark guidance are retained in `licenses/simple-icons.txt` and `licenses/simple-icons-13.txt`. React Native shares the React mark; C++ GDExtension uses the C++ mark alongside the separately listed Godot logo. Additional languages and creative applications were supplied directly by Ralph Christian Borbon.
- Project media: supplied directly by Ralph Christian Borbon. RELAYA and TUGONEX use the original logos; Albularyo’s Apprentice uses the supplied title screen; Upocalypse Control uses its main-menu screen; E-HAW uses the supplied project image. Original files are retained unmodified in `projects/media/`. Responsive PNG cards retain the logos’ colors and the complete screenshots at their original aspect ratios, with outlined editorial headings. The TUGONEX logo has a transparent background. Game screens and the E-HAW image are shown as small right-aligned thumbnails beside their project titles, without cropping. The game heading follows the supplied screen’s spelling, “Upocalypse Control.” Project stacks and descriptions come from the portfolio and supplied resume. RELAYA lists the documented AI approach because no implementation language or framework is specified in those sources.
- Animation: two local GIF banners, each with seven frames and a 5.81-second cycle. Brief cyan/red slice offsets affect only the headline; the base composition remains readable. The README selects static SVG versions when reduced motion is requested.
- Contributions: real daily counts from the [public GitHub calendar](https://github.com/users/ralphchr/contributions), including whatever contribution visibility the profile owner has enabled. The desktop asset shows the past year; mobile shows the last thirteen calendar weeks. No counts are fabricated.

## Refreshing the contribution calendar

`python scripts/update-contributions.py` fetches the public calendar and regenerates both contribution assets using only Python’s standard library. No credentials or third-party statistics service are required. An invalid response fails before existing artwork is replaced.

`.github/workflows/contributions.yml` refreshes these assets daily at 03:17 UTC (11:17 AM Asia/Manila), on manual dispatch, and when the generator or workflow changes on the default branch. It commits only changed contribution artwork. The scheduled refresh starts after these files are pushed to the profile repository’s default branch and GitHub Actions is enabled. Repository rules that prohibit bot pushes may require a manual update instead.
