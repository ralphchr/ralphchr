# Asset sources and maintenance

- Typography: Inter Black and JetBrains Mono from the portfolio’s existing `@fontsource` packages. Banner lettering is converted to SVG paths, so GitHub does not need custom fonts or external font files. The tagline uses the same JetBrains Mono typeface as “AN ONGOING PRACTICE.” Original font licenses are in `licenses/`.
- Technology and application icons: [Simple Icons 16.0.0](https://github.com/simple-icons/simple-icons/tree/16.0.0), with Adobe and Canva marks from [Simple Icons 13.21.0](https://github.com/simple-icons/simple-icons/tree/13.21.0), recolored cyan and framed locally. Icons are CC0; licenses and trademark guidance are retained in `licenses/simple-icons.txt` and `licenses/simple-icons-13.txt`. React Native shares the React mark; C++ GDExtension uses the C++ mark alongside the separately listed Godot logo. Additional languages and creative applications were supplied directly by Ralph Christian Borbon.
- Project showcase: responsive SVG editorial indexes (`project-index.svg` and `project-index-mobile.svg`) list each project’s domain and documented stack using Inter Black names, JetBrains Mono annotations, and small icon-and-name chips. Language/framework logos reuse the local Simple Icons assets; AI, speech recognition, NLP, and GDExtension use original generic symbols, not vendor logos. No table markup, CSS, JavaScript, project logos, or screenshots are used in this section. The image alt text includes every project, domain, and stack. Descriptions and technologies come from the portfolio, supplied resume, and direct user updates. RELAYA lists its documented AI approach because those sources do not specify an implementation language or framework. The name “Upocalypse Control” follows the supplied game screen. Previously supplied logos, screenshots, and generated cards remain under `projects/` as reference assets; they are not displayed in the current README.
- Animation: the 1200 × 480 banner is used at every viewport size, preserving its 5:2 aspect ratio as it shrinks on phones. The GIF has seven frames and a 5.81-second cycle. Brief cyan/red slice offsets affect only the headline. Reduced-motion preferences select the static SVG with the same dimensions. Earlier compact mobile banner files remain as unused reference assets.

- GitHub statistics: the Consistency card uses [GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats), configured for `ralphchr` and weekly streaks, with cyan and purple (`#8B5CF6`) accents. It is served live by the provider and follows its cache/availability. Only the public GitHub username is sent to the image endpoint. Counts from the supplied reference screenshot are not copied.
- Git Activity: original local SVG line graphs derived from real daily counts in the [public GitHub calendar](https://github.com/users/ralphchr/contributions). Desktop and mobile show the same last 31 days; mobile uses fewer date labels. The monotone curve passes through actual counts and the SVG point tooltips retain exact dates and values. Invalid upstream responses are rejected before existing artwork is replaced.

## Refreshing Git Activity

Run `python scripts/update-activity.py` to regenerate the desktop and mobile line graphs using Python's standard library. `.github/workflows/activity.yml` refreshes the graphs daily at 03:17 UTC (11:17 AM Asia/Manila), on manual dispatch, and when the generator or workflow changes on the default branch. This activates after pushing to that branch with GitHub Actions enabled; repository rules must permit bot commits. The older calendar heatmap and its workflow remain removed.
